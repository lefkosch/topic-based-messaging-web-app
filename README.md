# Topic-Based Messaging Web App

A web application developed as part of coursework at Harokopio University of Athens, enabling users to create topics and exchange messages based on shared interests.

## Overview

This project focuses on frontend development and integration with backend and database functionality in a dynamic web environment.

## Technologies

* Java
* HTML
* CSS
* JavaScript
* MySQL

## Features

* User login
* Password update
* Topic creation
* Message submission
* Form validation
* Interaction with backend services

## My Contribution

* Developed the frontend using HTML and CSS
* Implemented client-side functionality with JavaScript
* Built form validation and user interaction flows
* Integrated frontend with backend and database functionality

## Notes

This project was developed as part of academic coursework. The backend and database foundation were provided, while the frontend and integration logic were implemented by me.
